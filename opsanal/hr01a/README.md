### Key Fields
- **ACTYPE**: Specifies the type of military operation of the action being reported. (Type: A: Artillery; B: Base Defense; G: Infantry; R: Reconnaissance Bn, Length: 1)
- **TACTA**: Identifies a specific tactical area of operation in which the action took place. (Type: TACTA.json, Length: 1)
- **JYEAR**: Identifies the year in which the reported action occurred. The '6', first digit value is generated by the preprocessor and prefixed to form part of the record id. (Type: Numeric, Length: 2)
- **JDAYS**: Identifies the day, in Julian date notation, in which the reported action occurred. (Type: Numeric, Length: 3)
- **RCSEQ**: Provides a space in the record ID in which to sequence an overflow record. (Type: Numeric, Length: 1)
- **MONTH**: Month-of-the-year identification of the action. (Type: 01-12, Length: 2)
- **DAY**: Day-of-the-month identification of the action. (Type: 01-31, Length: 2)
- **QUATR**: Year quarter notation of the action (Type: 1st-4th Quarter, Length: 1)
- **USIZE**: The size of the friendly unit involved in the reported action. (Type: USIZE.json, Length: 2)
- **OPLPD**: If ACTYPE is 'G' or 'B' and USIZE is 'CO', data represents clearing actions. If ACTYPE is 'G' or 'B' and USIZE is not 'CO', data represents day observation post/listening post action. If ACTYPE is 'R' data represents day sightings. (Type: Numeric, Length: 3)
